# Austin's Tech Repair Group - Official Website

Welcome to the official web repository for **Austin's Tech Repair Group**, providing professional, on-site mobile consumer electronics diagnostics and component-level repairs across the Miami Valley region.

## 🛠️ About The Project
This website serves as the digital storefront and customer portal for the business. It allows clients to view service offerings, understand transparent pricing models, learn about the **ATR One** membership program, and get in touch for on-site technical support.

## 💻 Tech Stack
* **HTML5** – Semantic markup and page structure
* **CSS3** – Modern, responsive styling and layout
* **JavaScript (ES6+)** – Interactive UI elements, dynamic pricing calculators, and form handling
* **GitHub** – Version control and code deployment

## ✨ Key Features
* **Service Catalog:** Details for smartphone, tablet, computer, smart watch, gaming console, and television repairs.
* **Transparent Pricing Model:** Clear breakdown of labor rates, dispatch fees, and device tune-up options.
* **ATR One Membership:** Dedicated section highlighting the $19.99/month subscriber benefits, including priority queuing and remote support.
* **Mobile-Responsive Design:** Optimized for seamless viewing on smartphones, tablets, and desktops.
