## Reporting a Vulnerability

We take the security of our software and systems seriously. If you discover a security vulnerability, please report it responsibly rather than opening a public issue.

* **Where to report:** Send an email directly to our security contact or use GitHub's private vulnerability reporting feature for this repository.
* **What to include:** Please provide a detailed description of the vulnerability, steps or proof-of-concept code to reproduce it, and any potential impact assessment.
* **What to expect:** You will receive an initial acknowledgment of your report within 48 to 72 hours, followed by updates as we investigate and coordinate a fix. 

We appreciate your help in keeping our projects and users safe!
